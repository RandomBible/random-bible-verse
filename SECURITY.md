# Security policy

## Supported versions

Security fixes go into the latest published version of `random-bible-verse` and the latest
release of the WordPress plugin. The embed script at `https://random-bible.com/widget.js` is
always the latest version.

## Reporting a vulnerability

Please use GitHub's private reporting: open the
[Security tab](https://github.com/RandomBible/random-bible-verse/security) of this repository and
choose **Report a vulnerability**. Don't open a public issue for a security problem.

Include what you found, how to reproduce it and the version affected. We aim to acknowledge a
report within three working days and to tell you what we plan to do about it within ten.
